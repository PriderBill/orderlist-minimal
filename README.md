# orderlist-minimal

基于 Jekyll `minimal` 主题的静态站点，用于展示整理好的清单/列表内容。

## 简介

一个以「清单列表」为核心内容的轻量静态页面项目，基于 GitHub Pages + Jekyll minimal 主题搭建，实现极简的排版与导航。

## 快速开始

### 本地预览

```bash
# 安装 Jekyll 后执行
bundle exec jekyll serve
# 访问 http://localhost:4000
```

### 部署

推送到 GitHub 后由 GitHub Pages 自动构建，在线访问：

https://priderbill.github.io/orderlist-minimal/
